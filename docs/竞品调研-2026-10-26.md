# 竞品调研：同类开源产品还能给 Trove 什么

2026-10-26 调研。结论按「对 Trove 现有架构的适配度」排序，已经落地的会在开发日记里逐条记。

## 调研对象与来源

| 产品 | 定位 | 值得看的点 |
| --- | --- | --- |
| [Zotero](https://www.zotero.org/) | 文献管理器（Trove 的直接对标） | 期刊 RSS 订阅（Feeds）、重复条目合并、彩色标签、相关条目 |
| [Sioyek](https://sioyek.info)（[GitHub](https://github.com/ahrm/sioyek)） | 面向教材/论文的 PDF 阅读器 | **Smart Jump**：PDF 没有内嵌链接也能点引用标记跳到参考文献、点参考文献反查正文引用；右键预览目标内容；Portals 跨文档锚点 |
| [Koodo Reader](https://github.com/koodo-reader/koodo-reader) | 电子书管理+阅读 | 书架直接显示阅读进度、笔记导出到 Notion/Obsidian、内置翻译 |
| [Calibre](https://calibre-ebook.com/about) | 电子书库 | 阅读统计（reading stats）、虚拟库（Trove 的智能收藏集已覆盖） |
| [Okular](https://okular.kde.org) | KDE 文档查看器 | 批注最全（内联/弹窗注释、几何形状、印章）；批注可存 sidecar 文件 |
| [Joplin](https://joplinapp.org/) / Obsidian | 笔记 | Joplin 内置 KaTeX 公式渲染；Obsidian 双向链接 + 反链面板 |
| [Polar Bookshelf](https://github.com/burtonator/polar-bookshelf) | 知识库式阅读 | 增量阅读、区域截图高亮 |
| [Paperless-ngx](https://docs.paperless-ngx.com/) | 文档管理 | OCR、全文高亮搜索（Trove 暂不做 OCR，需要外部引擎） |

主要来源：各产品官网/文档、[Sioyek 功能总览](https://ahrm.github.io/jekyll/update/2022/08/30/sioyek-feature-overview.html)、[Koodo Reader 官网](https://www.koodoreader.com/en)、[Calibre 手册](https://manual.calibre-ebook.com/)、Joplin/Obsidian 对比讨论（[r/joplinapp](https://www.reddit.com/r/joplinapp/comments/1fi2j31/obsidian_vs_joplin_which_notetaking_app_fuels)、[bundl.run](https://bundl.run/compare/joplin-vs-obsidian)）。

## 选择理由

- **1/4/5/6** 是「数据都在手边，只差一层界面/解析」的功能，风险小、测试好写。
- **2（智能跳转）** 是竞品里学术价值最高、又几乎没人做进 Windows 本地阅读器的功能，且能复用现有文本层/选区坐标系。
- **3（双页对开）** 补齐阅读器最后一类常用布局；与已有的旋转/分屏共用页面槽机制。
- **7（双向链接）** 是笔记模块从「记录」走向「组织」的一步，先做独立笔记（Markdown）范围，富文本子笔记不掺和。

后续轮次候选：PDF reflow（10，改动面大建议单独一轮）。文内引注定位符已按简化口径落地（#13）。

## 2026-10-29 补充：横向扩到 10 款，并据此重排优先级

第一轮只对着 Zotero 找差距，容易把「它没做」误当「不该做」。这轮把 Sioyek、LiquidText、MarginNote 4、Readwise、JabRef、Okular、calibre、Paperless-ngx、Koodo 一起摊开看（完整矩阵见《Trove 与 Zotero 功能差距评估报告》第五版第四章），结论有三条：

1. **行业共识该补就补，而且都能用自己的数据结构做**：跳转、对开、统计、复习、全文检索。其中「复习」已经落地——`src/recall.js` + 工具栏「回顾」，把标注按 SM-2 排期推回来，本轮 `test-recall` / `test-recall-ui` 共 87 项断言覆盖。
2. **一家之言要敢不做**：LiquidText 的摘录画布、MarginNote 的脑图、Zotero 的 Word 活引用、Readwise 的多源聚合，要么与「本地单窗口」冲突，要么成本远高于收益。写进「明确不做」并附理由，省得每轮重新讨论。
3. **下一轮候选（按投入产出）**：
   - **citekey 模板**（JabRef 的 `[auth][year][title:abbr]` 与修饰符）——纯数据层 + 设置项，LaTeX 用户直接受益；
   - **阅读标尺 + 命令面板**（Sioyek）——几十行换很高感知；
   - **印章标注与批注归档单文件**（Okular）；
   - **相似文档**（Paperless-ngx）——复用已有的索引 worker 算词向量最近邻；
   - **跨文档 Portal**（Sioyek）——对照栏现在要手动选文件，按引用自动跟随是 Smart Jump 的自然延伸。

老账仍在：中文文字标注的字体子集、从参考文献表批量入库、PDF reflow。三项各自单独一轮。
