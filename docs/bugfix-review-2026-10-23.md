## 验证结果

- 64 个 Node 启动的测试脚本全部通过，包括新增的 6 个回归脚本。
- 画笔、真实鼠标、懒渲染 3 个直接运行 Electron 的测试全部通过：合计 67 个源码测试脚本。
- 新增回归覆盖写满 / 替换失败、缓存和撤销一致性、10 MB 资源恢复、同名文件避让、迁移与恢复的提交失败、未保存 DOI、标注关联、自动索引及大列表交互。
- 所有数据操作使用临时资料库 / userData；下载测试使用本地 HTTP 服务，DOI 参数验证使用进程内替身。
- 现有 build 产物没有重建，因此本轮没有把旧安装包测试结果计为新代码验证。

同一台机器、相同生成器的单次测量；数据为无附件的模拟题录，每条一个作者和标签。此结果反映大库刷新，不代表所有真实资料库的搜索、磁盘和渲染耗时。挂载数量会随视口与滚动变化。另以混合正常 / 缺失附件的 1,000 行验证滚动到底、跨块键盘选择、复选框状态恢复和双击阅读。

400 页 PDF 独立性能检查通过：首屏可用 194 ms，远跳 39 ms，翻阅后保留 2 页位图；未观察到此次修改破坏原有 PDF 懒渲染。

## 保留边界

- 中文文字标注仍不能可靠写入 PDF 副本；现在会明确提示遗漏，原始标注数据保留。
- JSON 备份托管资源限 60 MB；外部引用的文档不在 JSON 备份内，全文索引可重建。
- 多文件提交在捕获写入错误后回滚，未引入跨文件断电事务；回滚本身失败时保留恢复副本并报告目录。
- 未进行视觉重设计，没有添加同步、引用插件、OCR 或其他产品功能。
